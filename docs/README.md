# Documentación de GitLab MR Board

Esta documentación explica la estructura, las decisiones, el desarrollo, la operación y las reglas funcionales del proyecto. El [README de la raíz](https://github.com/NGiudiDev/gitlab-mr-board/blob/main/README.md) ofrece la introducción breve y [`AGENTS.md`](https://github.com/NGiudiDev/gitlab-mr-board/blob/main/AGENTS.md), las reglas para mantener código y documentación.

## Secciones

- [Arquitectura](architecture/README.md): límites del sistema, backend, frontend e interfaz visual.
- [Decisiones](decisions/README.md): motivos y consecuencias de las elecciones técnicas relevantes.
- [Desarrollo](development/README.md): entorno local y estrategia de test.
- [Despliegue](deployment/README.md): build y operación en producción.
- [Dominios](domains/README.md): reglas funcionales de merge requests y de la vista personal.

Para empezar, instalar y ejecutar el proyecto siguiendo [Entorno local](development/entorno-local.md).
