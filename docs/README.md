# Documentación de GitLab MR Board

Esta documentación explica la estructura, las decisiones, el desarrollo y las reglas funcionales del proyecto. El [README de la raíz](https://github.com/NGiudiDev/gitlab-mr-board/blob/main/README.md) contiene la instalación, la configuración y la ejecución; [`AGENTS.md`](https://github.com/NGiudiDev/gitlab-mr-board/blob/main/AGENTS.md), las reglas para mantener código y documentación.

## Secciones

- [Arquitectura](architecture/README.md): límites del sistema, backend, frontend e interfaz visual.
- [Decisiones](decisions/README.md): motivos y consecuencias de las elecciones técnicas relevantes.
- [Desarrollo](development/README.md): calidad de código y estrategia de test.
- [Dominios](domains/README.md): reglas funcionales de merge requests y de la vista personal.
