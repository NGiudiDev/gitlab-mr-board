# Dominios

Cada página es la fuente de verdad de un conjunto de reglas funcionales:

- [Cuentas](cuentas.md): pertenencia al equipo, invitaciones, roles y aislamiento.
- [Autenticación](autenticacion.md): identidad, contraseñas, sesiones y gestión de usuarios.
- [Configuración de GitLab](configuracion-gitlab.md): proyectos y access token compartidos por la cuenta.
- [Merge Requests](merge-requests.md): clasificación, responsables y fecha de subida.
- [Vista personal](vista-personal.md): proyección de las tareas pendientes de una persona.

La composición técnica de estas reglas está en [Arquitectura](../architecture/). Los ADR explican decisiones históricas; estas páginas describen el comportamiento vigente.
